# Runbooks

Runbooks document repeatable operational procedures: production build/deploy validation, annual rollover, show-finalization recovery, payment reconciliation, data repair, and incident handling. They describe **how to operate** the system; they do not define gameplay design or canonical business rules.

Future runbooks use this structure:

```md
# [Procedure]
## Purpose
## When to use
## Preconditions
## Commands / steps
## Verification
## Failure handling
## Data safety
## Related architecture/design references
```

Stage 8 creates this framework only; no detailed runbook is added.
